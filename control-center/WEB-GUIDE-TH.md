# เว็บควบคุม streamer+

เว็บใช้งาน: https://thtopppppp666.lat/

ลูกค้ากรอก License key ของตัวเอง แล้วกดสร้างคำสั่งติดตั้ง คัดลอกไป PowerShell และยอมรับ UAC โปรแกรมรุ่นใหม่จะติดตั้งและตรวจ key อัตโนมัติ เจ้าของไม่ต้องกรอก key แทนลูกค้า

ปรับ Aim Assist, FOV, Smoothing, Sticky Aim, ขนาด FOV, Sensitivity, ปุ่มเมาส์เล็ง และการแสดงเมนู จากนั้นกดบันทึกและส่งไปโปรแกรม โปรแกรมต้องเปิดและเชื่อมต่ออินเทอร์เน็ตจึงรับค่าได้ เว็บแสดงสถานะออนไลน์และการยืนยันรับค่า ปุ่มลัดบนเครื่องยังทำงานได้ ค่าจะส่งใหม่เมื่อบันทึกจากเว็บ

ต้องติดตั้ง EXE รุ่นใหม่ที่รองรับเว็บ ไฟล์เดิมไม่มีตัวรับค่า เว็บนี้ให้ลูกค้าปรับค่าของ license ตัวเองเท่านั้น ไม่มี Seller Key ในหน้าเว็บหรือคำสั่งติดตั้ง คำสั่งมีโทเคนใช้ครั้งเดียว อายุ 30 นาที ตัวติดตั้งเก็บ license ด้วย Windows DPAPI และดาวน์โหลด EXE จาก R2 ส่วนตัวพร้อมตรวจ SHA-256

โค้ดเว็บ/API: public และ src
โค้ดโปรแกรม: app-source
ไฟล์ build: release-web/streamer+.exe

ทดสอบแล้ว: automated tests 7 รายการผ่าน รวมแยกข้อมูลตาม key, CSRF, revision, token replay และตรวจ license; ล็อกอินเว็บจริง สร้างคำสั่ง และเปิด EXE รุ่นใหม่รับค่า FOV 330 พร้อมยืนยันออนไลน์สำเร็จ ระหว่างทดสอบ Aim ปิดอยู่ ไม่ได้ทดสอบการเล็งในเกม

การเผยแพร่ซ้ำ: npm test แล้ว npx wrangler deploy
หาก build EXE ใหม่ ต้องอัปโหลด R2 และอัปเดต EXE_OBJECT กับ EXE_SHA256 ใน wrangler.jsonc ก่อน deploy
